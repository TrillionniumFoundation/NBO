\section{Replayed and newly constructed objects}
There are sixty-four inherited R46 objects: thirty-two constant/restart-price certificates, sixteen price-strengthened roots, and sixteen complete price-strengthened trees. The present revision replays every object using the independently implemented readers. The current local replay accepted all sixty-four and recorded per-object hashes and elapsed time. It did not rerun the optimizers or change any frozen endpoint.

The new witness constructor creates sixty-four further objects, four precision levels on each unchanged model. These are not sixty-four independent environments. Each includes the operating lower and upper witnesses, nonnegative prices inherited from a checked source certificate, a directed lower potential, one common repaired policy, its implementation cost, and explicit error budgets. A separate standard-library reader checks all of these without importing the constructor or a solver. It uses an unshifted potential representation to reconstruct the lower recursion. It also checks operating sub-/supersolution inequalities, probability simplices and grids, original model/protocol hashes, and the stronger upper-witness all-restart inequalities. All sixty-four pass.

Fifty-one deliberately malformed witness objects are rejected, with three valid controls accepted. The mutations separately alter endpoints, probabilities, policy length, terminal/operating enclosures, transformed potentials, cost budgets, model/source/protocol identity, target, and precision. They are smoke tests, not a proof of verifier completeness. The inherited price/tree property and mutation tests remain distinct. The mathematical proofs establish the general results; finite replay establishes only the declared finite objects and arithmetic contracts.

\section{Success criteria and exclusions}
The primary criterion is exact absolute width at most $1/1000$. Original frozen B and A counts are four and five of twelve primary cases, with no tie successes. The retrospective price tree attains six primary and three tie targets. The certified scalar portfolio attains nine of sixteen. In the witness-only precision audit four targets are met at each of four precisions; those intervals use the price-only lower, not the stronger tree lower. I0 is zero cost; T0's operating value is exactly representable. Neither is described as a difficult approximate-oracle test.

SCIP native lower bounds are excluded from every exact portfolio. Only its independently evaluated feasible policy may supply an upper endpoint. A newly reconstructed price certificate is not a post-certification of that solver's nonlinear global lower value. No native bound has been promoted by a name change. The original thirty positive-cost continuous intervals and the nonlinear experiments are not newly closed, and no empirical calibration is asserted.

\section{Reproduction commands and data boundary}
From the repository root, the complete publication can be rebuilt with
\begin{verbatim}
bash R47_BUILD.sh
\end{verbatim}
The build does not rerun the original optimizers. Its central commands are
\begin{verbatim}
python revisions/2026-09-26-r47/replication/replay_r46.py
python revisions/2026-09-26-r47/replication/witness_audit.py

\end{verbatim}
The price replay needs the inherited R44 and R46 readers and models. The witness construction and reader use only Python standard-library exact arithmetic. Figure regeneration additionally uses matplotlib. PDF production uses the retained, unmodified Econometrica \texttt{econsocart} class and pdfLaTeX/latexmk. Python package versions, the TeX build output, platform metadata, and all final content hashes are recorded by the publication build.

The source transfer is verified before extraction into normal files. No transport chunk is an article, and no restoration operation is needed by a referee to read the final PDFs or source tree. The publication manifest records source, table, proof, result, and PDF hashes. The inherited-file check verifies that the baseline tracked objects are not modified or removed by publication. The final Git commit gives the immutable review identity; a manifest does not try to contain its own hash or its future commit hash.
