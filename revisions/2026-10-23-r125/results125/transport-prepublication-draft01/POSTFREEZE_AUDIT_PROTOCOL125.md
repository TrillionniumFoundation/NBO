# Separately frozen post-primary independent verification, R125

This is an explicitly post-primary verification follow-up. It is not the
original F125 preregistration, does not alter any production decision, and does
not replace the original completed independent audit. That original 128-bin
audit remains 850/936 contained intervals and 193/251 independently confirmed
accepted gain bounds, with zero contradictions. The unchanged primary data,
original audit checks, evaluations, complete rational terminal witnesses,
summary and process receipts are bound in the new manifest and published before
the first new independent terminal computation.

## Deterministic complete selection

Read every original `results125/independent/checks125.jsonl` row. If either its
containment or its gain-confirmation flag is false, include both its actual
final-action key and completed-prefix key. Take the set union and sort by the
stored SHA256 key identifier. This selects all 110 affected action keys without
an economic outcome filter, representation selection, model change, or new
state draw. In the original audit the unresolved rows are 84 warm-fixed512
rows and two action-grid DP rows; their prefix pairs are all retained.

Every selected action receives exactly one 512-bin independent original-law
evaluation with 32 terminal bisection steps, using the unchanged standard-library
`independent94.py` primitives and unchanged `exact121.py` evaluation formula.
No additional level, including 2048, is authorized by this follow-up. Maximum
requested terminal contexts are exactly 110*(2*512+1)=112,750. A mismatch in
the expected complete selection fails before any economic call.

## Exact witness reuse and costs

The original audit already saved exact rational terminal witnesses. Such a
witness is reused only when both its rational terminal state and original risk
level are identical, and, when a state-gradient support is required, that support
is actually present. Duplicate cached state/risk keys must have exactly equal
action, lower and upper values. The nested shock mesh makes old mesh nodes
new endpoints. No production certificate or old fitted result substitutes for
an independent terminal witness. Every reused record retains the original
terminal-trace SHA256 and row sequence. Every newly computed terminal witness,
original primal/dual identity, bisection count and full evaluation is saved.

Record requested contexts, reused contexts, actually recomputed terminal
contexts, exact bisection counts, rational checks, whole child and parent clocks,
and the cache-loading cost. The 798.411727-second original audit remains charged
and is never treated as free merely because some witnesses are reused. New
work is an additional research-verification cost, not a recounted production
service timing. The source-derived no-reuse worst case is 112,750 new terminal
contexts; reuse lowers actual work, which is reported after execution. Based on
the already executed original audit, approximately 20--30 further minutes is a
planning estimate, not a claimed successful runtime.

## Reporting and boundaries

For selected keys, intersect old and new independently valid value intervals
and keep the larger independent global lower bound. Retain old evaluations for
all other keys. Recheck all 936 original rows and all 251 accepted gains, while
reporting original-audit and follow-up counts in distinct fields. Contradictory
intervals or opposite exact gain bounds fail the follow-up. Remaining unresolved
checks remain unresolved, without changing any acceptance or target indicator.

`POSTFREEZE_AUDIT_FREEZE125.json` binds the new protocol/code and every selected
input evidence file. `POSTFREEZE_AUDIT_BOUNDARY125.json` must name the new actual
remote source commit, confirm readback before new economics, and match the
manifest SHA256. Frozen F125 scientific files remain unchanged. All output uses
a new exclusive `results125/independent-followup512` directory and a separate
`launch-independent-followup512` parent receipt. Every failure and partial output
is preserved. This deterministic verification supplies no population inference
and cannot change the original experimental state design or initial audit.
