# Preserved navigation and scientific history

The assembly process stores the preceding current index as `REVISION_INDEX_before_R42.md` and keeps the earlier index snapshot separately. This directory is present before a clean-checkout build begins.

The full original R40 article and technical supplement remain unchanged in their original locations. `HISTORY_R42.pdf` combines their pages without editing them. The publication verifier rejects changes to any inherited scientific file and checks the archived current index byte-for-byte against the frozen R41 base.
