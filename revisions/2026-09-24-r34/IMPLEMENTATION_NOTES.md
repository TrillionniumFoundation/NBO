Parent: `88015b77a0c26e7b883156410b684b229fd7e86f`. Reviewed R30: `3394815f4ccbf5917582c8f756b535adf87783cc`; latest review commit: `e9bc144fbb6843d6a3436825a28584efb64fb8f1`. The R34 branch begins from the parent and does not merge into main or any preceding revision/review branch.

No old class construction is a free input in the work account. No neural training is rerun. Training time in the inherited tables is labeled as inherited and is never pooled with new-machine incremental timing.

## Exact reference and remote reproduction

`EXPECTED_EXACT.json` binds every one of the 294 locally constructed, independently audited scientific certificate objects by canonical uncompressed SHA-256, and binds the frozen inputs and journal class. The publication script requires the remote run to reproduce every hash. Floating runtime measurements, environment identifiers, and PDF metadata are intentionally excluded from this identity: they are new measurements on each machine. The printed tables are regenerated from that machine's actual execution, with new lower/upper interval endpoints rounded outwards.

`run_study.py` charges and records the support-stage constructor and first read-only audit. `run_closure.py` records finite-tree tests, the entire closure cohort, and a fresh full audit which first rechecks all support/base objects and then all closures. The final audit therefore supersedes, but does not erase, the first audit. Both command ledgers remain present, and no repeated audit is hidden in a solver-speed comparison.

The independent checker disables all envelope optimizer bindings; it shares exact representation, affine composition, and comparison primitives. It is not a proof assistant or an independent second arithmetic engine. Every open-cell endpoint limit and every actual isolated knot value is checked. The new theorem's history-dependent extension requires conditional feasibility at each evaluated history; it does not impose that stronger interpretation on an initial-expectation-only constraint.

## Results and limits

All 42 fixed deployments are feasible and preserve installed returns. All 18 installed-neural cases cost less than the local-class minimum; this is not evidence of neural-specific speedup. The restart propagation tightens 22 global lower bounds, leaves 20 unchanged, and makes no additional unrestricted support solve. Twelve spline deployments retain zero global gap; no positive gap closes. Maximum absolute tightening is about 0.261684 and maximum relative global-gap reduction about 38.51%. All exact metrics and all unchanged cases are published.

The original stopped-economy all-domain .01 target and current bound 7.181834580823298 remain unchanged by this maintenance computation. The complete constant-control active-boundary proof is retained and its rational inequalities rerun. Its endpoint payoff enclosure is inherited quadrature, not a newly run feedback or payoff computation. Strong neural-specific acceleration, a high-dimensional application, and measured deployment-query amortization remain outside the demonstrated results.
