# Paid-support action safeguard: implementation handoff

## Identity and novelty boundary

The frozen prior R120 has paired action differences and safe gates; R121 has original marginal regularity, finite-difference labels, a finite-box fit and an unexecuted feature cover. This new addition converts the original certificate's already paid **quadratic support gap** into a **sharp derivative information interval**, with explicit capacity asymmetry; it then uses an outward smooth-descent envelope to propose and qualify an actual improved policy without a second-action oracle if all tests resolve. Smooth Taylor descent and cost dominance are classical inequalities; do not claim them or the construction are neural-exclusive. The sharpness result is for the specified support-information class, not for every algorithm with complete investment formulas.

## Safe formulas

For any 0<hplus<=A-a, gminus=pminus-e/hplus-(L-2)*hplus/2.
For any 0<hminus<=a, gplus=pplus+e/hminus+(L-2)*hminus/2.
Each side can minimize its radius over feasible h independently. At missing room do not infer the missing side. Use the separately proved [-7,7] original derivative bound to make the interval finite.

Robust upper contrast Umodel(d)=max(gminus*d,gplus*d)+L*d*d/2. Lower contrast Lmodel(d)=min(gminus*d,gplus*d)+d*d.
Realized action b=a+d must be feasible after rounding. Actual J(b)-J(a) lies in [Lmodel-delta,Umodel+delta], delta=(15/16)*2^-20.
Candidate J upper Ub=U+Umodel+delta. Candidate lower Lb=W+min(pminus*d,pplus*d)+d*d. Retain old policy if unresolved or use separately paid fallback.

For the ideal robust step, if gminus>0 take d=-min(a,gminus/L); if gplus<0 take d=min(A-a,-gplus/L); otherwise d=0. Reevaluate all bounds at actual rounded b, do not certify ideal step instead.

## Important limits

A low support gap cannot yield both derivative sides at a capacity boundary. No global feature cover is claimed. An exact derivative still leaves Taylor value width (L-2)*d*d/2+delta; gain can resolve while the reporting-width test cannot. A finite precision ladder is guaranteed only if the original value/support oracle actually has the stated error and cost properties. Cost stopping is a narrow proven dominance region with specified compulsory next work, not a global optimum scheduling theorem. Every comparison representation gets the same data and safeguard. Old samples, methods, clocks and experiments stay unchanged.
