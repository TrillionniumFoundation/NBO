## M3 / B5. Validation independence and adaptive deployment

The retained study separates predictor-independent validation contexts from contexts visited during deployment, and the intervening deployment theorem conditions on the actual history. R73 adds the corresponding distinction for policy-cost qualification. Before an episode, its complete controller pair, continuation and support must be fixed given the preceding history. The continuation can change predictably between episodes without changing the expected original-law cost difference of a fixed controller pair. Within an episode it remains frozen for the telescoping identity.

The new cost theorem does not require independent, identically distributed deployment contexts. It bounds the average conditional expected cost difference under the stated conditional laws. That average equals one fixed policy-cost contrast only when the complete controllers, initial law and reset contract stay fixed. A program with a cache carried between episodes can have a changing conditional target despite an unchanged code identifier. The manuscript and ledger therefore require a new error-allocated epoch for a changed fixed target. History-dependent controller memory must be included in the policy description and in the uniform greedy-gap qualification. Neither changing contexts nor reused validation data are silently treated as new independent evidence for the final controller.

## M9 / B9. The economic decision and its units

The economic object remains the actual feasible investment controller and the cost of constructing, qualifying and replacing it. The new stopping theorem permits a well-defined decision: stop qualification when the upper incremental-cost endpoint, plus an explicitly priced setup charge per declared deployment and a per-deployment charge, is negative. Measured processor seconds are not silently assigned a monetary value. The deployment count over which setup is amortized is not automatically the number of qualification episodes.
