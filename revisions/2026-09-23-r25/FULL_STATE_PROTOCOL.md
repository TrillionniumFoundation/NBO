# R25 original-economy current-state continuation

This additional experiment is prescribed before its execution. It does not change or retune the separate held-out financed-policy study. It directly continues the original current-state actor/witness problem, rather than using the manufactured benchmark as a substitute.

Warm start: the complete actor and critic in revisions/2026-09-23-r22/results/full_state/candidate_network.json. Keep the original k=2 economy, action comparison set, state-time domain, accessibility-constrained actor architecture, 2^-24 pre-distance output contract, and 2500 trainable parameters. Use the unchanged R17 ordinary differentiable interval surrogate only to propose updates, and the independent unchanged R16 MPFR checker to certify candidates.

Four sequential blocks, each capped at 500 function/gradient calls of L-BFGS-B (maxls 40, ftol 1e-13, gtol 1e-8). Training cover: (4,16,16); smooth-max temperature 0.05. Each block restarts L-BFGS-B from the currently retained actor/witness, and returns its last accepted optimizer iterate on a call cap. After each block run the complete (4,16,16) MPFR audit. Compute the all-start-time discounted suffix envelope using directed MPFR arithmetic. Retain the candidate only if its certified uniform regret upper bound strictly decreases. On rejection restore both actor and critic before the next block. Preserve every candidate, every complete-cell certificate, every optimizer history and every rejection.

After the four decisions, certify BOTH the untouched R22 warm start and the retained R25 candidate on the fixed finer cover (8,32,32), with zero skipped cells. Separate improvement due to finer checking from improvement due to changed network weights. Report every start-time slab envelope, entire-domain maximum, generation, coarse-check and fine-check times. The original target remains 0.01. A decrease in an upper bound on regret is not, by itself, proof of a policy-specific payoff improvement. No such payoff claim is allowed without a separate lower/upper policy comparison.

This is an online certificate-coupled actor/witness refinement for the original state, separate from the online payoff-acceptance experiment in the financed family. Neither experiment is asserted to converge merely because retained certificates improve monotonically. The current manuscript must report any remaining distance to the original full-domain target, even if the auxiliary stochastic benchmark attains its own target.
