\section{Reproduction}
From the repository root, set \texttt{OPENBLAS\_NUM\_THREADS=1}, \texttt{OMP\_NUM\_THREADS=1}, and \texttt{PYTHONINTMAXSTRDIGITS=0}. Run the registered \texttt{replication/run\_suite.py}, then \texttt{replication/audit.py} and \texttt{replication/assemble.py} under the R43 directory. The optional \texttt{resume.py} reuses only existing v2 objects that pass a fresh independent endpoint check; it does not change the registered numerical implementation. Compile the four root-level R43 wrappers with \texttt{latexmk -pdf -interaction=nonstopmode -halt-on-error}. The publication step checks missing references, overfull horizontal boxes, PDF readability, source hashes, exact endpoint identities, and preservation against the R42 base.

The independent checker uses only Python's standard library and can be run without NumPy, SciPy, an optimizer, or LaTeX. Full numerical regeneration additionally requires NumPy and SciPy. Publication requires the unchanged Econometrica support files, LaTeX, and PyMuPDF. The complete current environment and manifest are stored with the results.
