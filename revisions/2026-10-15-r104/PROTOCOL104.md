## Fixed questions
H1: action-derivative approximation alone can miss changes in the maximizing AVaR density. Prove a quantile-margin correction and an independently integrated exact counterexample. This develops, without claiming execution of, the tail-switching question also recorded by R101.
H2: original-objective support directions plus verified cost-interval descent can repair rejected NBO proposals before an expensive conventional fallback. Test actual policy cost, original-optimum loss, and all work. This is a safeguarded inexact descent method, not a claim that descent or KKT conditions are new.
H3: active-set evaluation can skip redundant terminal bisections without changing the inherited terminal controller. Separate this execution optimization from policy repair with a two-by-two service ablation. Equivalent conventional representations receive the same improvement.

## Four complete services
1. inherited legacy service;
2. legacy with active-set terminal evaluation;
3. safeguarded support repair with inherited terminal evaluation;
4. support repair with active-set terminal evaluation.

Active-set terminal evaluation computes both endpoint derivatives for all rows and performs the same fixed number of midpoint bisections only for rows not already assigned an endpoint by the inherited branch conditions. Maintain ordering, ties, action quantum and capacity clipping. Require exact output identity on executed comparisons; record operation savings separately from clocks. The mathematical identity is conditional on deterministic equal per-row arithmetic, not arbitrary compiler reassociation.

Support repair starts from the same realized feasible proposal and its 128-bin original-law certificate. For a proposal failing the final targets, form the clipped scalar support step a-s/2, with s the midpoint of the original feasible-witness slope interval. Try displacements 1, 1/2 and 1/4 of this step in that order, each rounded downward to the inherited 30-bit action grid and capacity. Accept a changed action only if its verified policy-cost upper endpoint is strictly below the incumbent lower endpoint. Stop if it also meets the original targets. After an accepted but unqualified action, recompute its direction, with at most three original-certificate trial calls in total. If no such repair qualifies, use and charge the unchanged legacy online repair, integration ladder and rational fallback. Retain all trials, refused changes and fallback work. A smaller regret upper bound alone is not a policy improvement. Root-state improvements concern the same fixed terminal policy; uniform replacement at every state requires the separately stated theorem's uniform hypotheses.

Seven sequential fresh-process timing repetitions use the first 32 evaluation states for all arms, risks and services, one computational thread.
