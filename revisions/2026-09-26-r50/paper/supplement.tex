\section{The price-family gap, rather than the common-policy gap}
For every historical unfinished row, all positive-support masks are either supplied with a feasible occupation upper witness or pruned using the masked cost of an explicitly checked feasible policy. The global upper bound covers the uncapped ideal clipped price optimum. Subtracting the capped replay value yields the displayed loss upper bound. It is not an upper bound on the gap to the original common-policy optimum. Small support, not the total number of states, determines the number of masks in the large R48 models.

\subsection{Shared-successor compatibility and rational conditioning}
For each nonzero incoming flow $f_{tij}$ of an occupation witness, the implied successor allocation is $\alpha_{tij}/f_{tij}$. The diagnostic records the largest spread of that quantity across incoming edges to one successor, maximized over retained occupation witnesses. A positive spread directly witnesses a lack of shared successor allocation in that particular feasible relaxation point. It is not a lower bound on the optimal common-policy gap, nor a regression claiming that spread causes observed tree time. Edges with zero flow have both allocation masses zero and impose no ratio restriction. Price and rational-size summaries distinguish numerical conditioning from arithmetic validity.

\section{Minimal external-facing benchmark specification}
A finite instance is the tuple $(n,T,m,\beta,\varepsilon,\nu,r,k,P,g)$ with rational entries, stochastic transition rows, and nonnegative implementation costs. A candidate policy is one simplex row for each $(t,i)$. Evaluate $V$, $J^p$, and $C^p$ backward using the recursions in the article, require $V_{ti}-J^p_{ti}\le\varepsilon$ for every state and date, and minimize $\nu C_0^p$. No hidden initial plan lottery is allowed. Third parties can reconstruct this optimization target from the JSON without importing project code.

A reset instance instead specifies $T,m,\beta,\varepsilon$, action productivities $\gamma_a$, affine coefficients of $g_t$ and $k_{ta}$, a uniform reset kernel, and a uniform initial law. A deployed cell policy is checked at both endpoints of every cell. The continuation moment is the full cumulative quantity $M_t=\int p_td_t+\beta M_{t+1}$, not just a one-period average. Its lower certificate minimizes over all Borel policy rows before integration. The Python and JavaScript readers implement these formulas separately. Both remain within-project implementations.
