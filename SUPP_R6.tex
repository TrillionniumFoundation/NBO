\runtitle{Neural Bellman Operators: Supplement}
\begin{aug}

\address[id=add1]{\orgname{Peking University}}

\begin{abstract}
This supplement provides the operator proofs, verification conditions, transition construction, additional numerical results, and replication instructions for the sixth revision. It distinguishes continuous-time economic objects from finite transition approximations and distinguishes trained neural policies from analytical and finite-state regression tests. The main paper and this supplement use the same policy-evaluation, boundary, and temporal-self conventions.
\end{abstract}
